My entry for [One Line, Zero Use: The Useless Superpower Sprint](https://make.fun/competitions/u-daring-gecko-25-one-line-zero-use-the-useless-01ca1c68) on make.fun.

> I can summon any object I own — as long as it's already in my hand.

One line, 67 characters, and the whole joke is in the tail: the power works flawlessly and changes nothing.

## How it runs

```sh
node main.ts
```

`main.ts` needs nothing installed and touches no network. It checks the line is between 1 and 200 characters, is not blank, has no stray spaces at either end and no newline, then writes it to `/output/entry.txt` as UTF-8 with no trailing newline, and reads the file back to prove it matches. Running it twice produces a byte-identical file.

## Why this line

Summoning sounds like the best power on the list until the fine print arrives: it only works on things you are already holding. The power is flawless, instant, and completely pointless — the punchline lands in the last few words, and every word before it is just setting the trap.
